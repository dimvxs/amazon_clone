# ORBIS

Современная платформа электронной коммерции, разработанная как командный дипломный проект.

ORBIS представляет собой онлайн-маркетплейс, вдохновлённый функциональностью :contentReference[oaicite:0]{index=0}, с возможностью просмотра товаров, управления заказами и взаимодействия пользователей с системой интернет-покупок.

---

## Основные возможности

- Регистрация и авторизация пользователей
- Каталог товаров
- Поиск и фильтрация товаров
- Корзина покупок
- Оформление заказов
- Личный кабинет пользователя
- Административная панель
- Адаптивный интерфейс
- Работа с базой данных
